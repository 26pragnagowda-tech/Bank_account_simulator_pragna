Bank Account Simulator

Project Description

The Bank Account Simulator is a simple menu-driven Python application that simulates basic banking operations. It allows users to check their account balance, deposit money, withdraw money, and view their transaction history through an interactive menu.

Objectives

- To understand functions and loops in Python.
- To implement conditional statements and input validation.
- To manage account balance using variables.
- To store transaction records using a list.
- To prevent invalid deposits and withdrawals exceeding the available balance.

Features

1. Balance Inquiry: Displays the current account balance.
2. Deposit Money: Adds a valid amount to the account balance.
3. Withdraw Money: Withdraws money if sufficient funds are available.
4. Transaction History: Displays all successful deposits and withdrawals.
5. Input Validation: Rejects invalid menu choices, non-numeric amounts, and amounts less than or equal to zero.
6. Exit Option: Allows the user to safely exit the application.

Technologies Used

- Programming Language: Python
- Concepts: Functions, loops, conditional statements, exception handling, lists, and variables.

How to Run

1. Install Python 3 on your computer.
2. Save the program as "bank_account_simulator.py".
3. Open the file using VS Code or IDLE.
4. Run the program.
5. Select an option from the menu and follow the instructions.

Conclusion

This project demonstrates the implementation of a basic banking system using Python. It provides practical experience with functions, loops, validation, and state management while maintaining transaction history. It is an educational simulator and does not connect to a real bank account.
